# Stephen Loiola Bastos — Portfolio v2

This project is a personal portfolio built with **Next.js** and **React 19**.

It uses a modern front-end architecture with:

- **internationalization**
- **light and dark mode**
- **content fetched from Strapi**
- **modular React components**
- **SCSS Modules** for styling

## Tech Stack

- **Next.js**
- **React 19**
- **TypeScript**
- **next-intl**
- **SCSS Modules**
- **Strapi** as a headless CMS

## Features

- Multilingual website
- Light and dark theme support
- Static page generation
- Content managed through Strapi
- Component-based architecture
- Responsive and modern UI

## Requirements

Before running the project, make sure you have:

- **Node.js**
- **pnpm**
- a working **Strapi** instance
